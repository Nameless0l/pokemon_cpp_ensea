# Pokemon Selector : introduction à la POO en C++ (IS_3436)

## Review de code 
 - Le projet est clair et structuré proprement
 - Le fichier README est clair et détaillé
 - On a la présence d'au moins un polymorphisme, un smart pointer, une lambda expression, une boucle *for* avec un itérateur, de vecteurs, la gestion d'une exception et les design pattern STATE et SINGLETON.

 - En testant le jeu, j'ai pu me rendre compte que les lettre avec accent (é par exemple) ne passent pas dans mon terminal (et affiche plutôt ├® à la place de é).
 - La sélection des pokemons dans son groupe d'attaque se fait via une interface graphique, ce qui est génial mais le jeu pourrait être encore meilleur si tout se fait via l'interface graphique avec notamment les phases d'arènes.
 - J'imagine que c'est un bug mais durant la phase d'exploration lorsqu'on veut voir son équipe, on ne peut voir que les pokemons qui ne sont pas dans le groupe d'attaque. L'ensemble de notre équipe n'est donc pas affiché.
 - Dans le jeu de base, il y a des objets utilisables lors des combats, ça peut être une fonctionnalité sympa à rajouter que d'implémenter les objets.
